# LTW-EXTRA
Allows LTW renderder to render less Translation 

## Features
1. Smart Filter - Remove duplicate OpenGL calls
2. Smart Merge - Merge small draw calls into one
3. Smart Cache - Don't re-translate same frame

## Works With
- Sodium (Friend, Not Enemy)
- LTW (Makes LTW faster)
- PojavLauncher
